# Telegram Mini App — каталог персонажей

Это стартовый проект каталога. В нём уже есть 12 согласованных разделов, просмотр персонажей, поиск и интерфейс администратора для добавления/изменения разделов, персонажей и изображений.

## Важно о безопасности
- Токен Telegram-бота не нужен этому фронтенду. Никогда не вставляйте токен бота в файлы сайта, GitHub или переменные `VITE_...`.
- Ранее отправленный в чат токен нужно отозвать через @BotFather (`/revoke`) и использовать новый.
- Не публикуйте `service_role` key Supabase. Для приложения используется только публичный anon/publishable key.
- SQL ниже задаёт чтение каталога всем посетителям и запись вошедшим пользователям. Для личного каталога создайте только свой аккаунт администратора и не раздавайте пароль.

## Что понадобится
1. Аккаунт GitHub.
2. Аккаунт Supabase (бесплатного плана достаточно для первого прототипа; у бесплатного плана есть лимиты и условия).
3. Аккаунт Vercel (для размещения веб-приложения).
4. Telegram-бот, созданный через @BotFather.

## Шаг 1. Создать базу и хранилище в Supabase
1. Откройте https://supabase.com/ и создайте проект.
2. В проекте откройте SQL Editor → New query.
3. Скопируйте весь файл `supabase/schema.sql`, вставьте в редактор и нажмите Run.
4. Откройте Project Settings → API (или Connect). Скопируйте Project URL и публичный anon/publishable key. Не копируйте `service_role` key.
5. Откройте Authentication → Users и создайте пользователя (Add user) с вашей почтой и надёжным паролем. Подтвердите пользователя, если Supabase попросит.
6. Скопируйте свою почту. В SQL Editor выполните запрос, заменив `email@example.com` на свою почту:
   ```sql
   insert into public.admin_users (user_id)
   select id from auth.users where email = 'email@example.com'
   on conflict (user_id) do nothing;
   ```
   Только этот аккаунт получит права редактирования каталога. Не создавайте и не раздавайте другим людям администраторские аккаунты.

## Шаг 2. Опубликовать проект на GitHub
1. Создайте репозиторий на https://github.com/new. Название, например `telegram-miniapp-catalog`. Можно выбрать Public, если не хотите настраивать приватный импорт на Vercel; секретов в коде нет.
2. Загрузите все файлы и папку `src` и `supabase` из этого проекта. Самый простой способ с телефона — GitHub в браузере → Add file → Upload files. Убедитесь, что `package.json`, `index.html`, папки `src` и `supabase` находятся в корне репозитория.
3. Не загружайте `.env` с ключами. В этом шаблоне его нет.

## Шаг 3. Разместить сайт на Vercel
1. Откройте https://vercel.com/ и войдите через GitHub.
2. Нажмите Add New → Project и выберите репозиторий.
3. Framework preset: Vite (обычно определяется автоматически). Build command: `npm run build`. Output directory: `dist`.
4. В Environment Variables добавьте:
   - `VITE_SUPABASE_URL` = ваш Project URL из Supabase
   - `VITE_SUPABASE_ANON_KEY` = ваш публичный anon/publishable key
5. Нажмите Deploy. После публикации Vercel покажет HTTPS-адрес вида `https://имя-проекта.vercel.app`.

## Шаг 4. Подключить Mini App к Telegram
1. Откройте @BotFather → `/mybots` → выберите бота.
2. Используйте настройку Main App / Configure Mini App (названия пунктов могут меняться) и укажите HTTPS-адрес Vercel. Если пункта Main App нет, настройте Menu Button через `/setmenubutton` и укажите URL.
3. В описании/кнопке можно написать «Открыть каталог».
4. Откройте бота и проверьте запуск приложения.

## Шаг 5. Проверить каталог
- На главной странице должны появиться 12 разделов.
- Откройте замочек в правом верхнем углу, войдите почтой и паролем, созданными в Supabase.
- После входа администраторского аккаунта появятся кнопки добавления/переименования/удаления разделов и добавления/изменения/удаления персонажей.
- Внутри раздела добавьте имя и выберите фото с телефона.

## Если что-то не работает
- Если видите «Демонстрационный режим», переменные Supabase не добавлены или сайт не был повторно опубликован после их добавления.
- Если ошибка входа — проверьте, что пользователь создан в Supabase Authentication → Users.
- Если картинки не загружаются — проверьте, что SQL из `schema.sql` выполнен целиком и bucket `catalog-images` создан.
- Если приложение не открывается в Telegram — проверьте, что в BotFather указан HTTPS-адрес Vercel, а не адрес GitHub.

## Примечания
- Это начальный рабочий шаблон, а не уже размещённый бот/сайт: его нужно подключить к вашим аккаунтам.
- Пока приложение работает как веб-каталог внутри Telegram. Отдельная отправка изображения сообщением в чат — дополнительная функция, которую можно подключить позже через серверную часть бота.
